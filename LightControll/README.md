# LightControll
  - Модуль проекта SmartHome потвечает за включение и выключение света, регулировку яркости.

## Структура модуля:

```text
LightControll/
├── .cargo/
│   └── config.toml          # Конфигурация компиляции и таргета (ESP32)
├── src/                     # Исходный код проекта
│   ├── bin/
│   │   └── main.rs          # Главный исполняемый файл (точка входа)
│   ├── lib.rs               # Основная логика, подключение модулей и макросов
│   ├── relay.rs             # Модуль управления освещения  
│   ├── wifi.rs              # Модуль подключения и работы с Wi-Fi
│   └── mqtt_handler.rs      # Модуль обработки соединений MQTT брокера
│   └── protected.rs         # Модуль работы с защищенными данными
├── build.rs                 # Скрипт сборки и компиляции 
├── Cargo.toml               # Конфигурация крейта и зависимости
├── sdkconfig.defaults       # Параметры конфигурации ESP-IDF по умолчанию
├── LICENCE                  # Лицензия проекта
└── README.md                # Документация проекта 
```

## Установка и запуск

### 1. Настройка констант и перечислений для запуска проекта:

* **Изменить файл protected.rs в соответствии с условиями своего проекта:**
  - Пометка: 
  ```text
    В 'BROKER_URL' прописать url своего mqtt брокера. 
    В 'SDDI' прописать логин wifi сети.
    В 'PASSWORD' прописать пароль wifi сети;
    'subscriptions!' - макрос, в котором необходимо прописать наименования перечислений контроля освещений.
    В 'netif_config' прописать параметры для статического ip адреса.
  ```
   - Подробнее о макросе [`subscriptions`](../Display/src/macros.rs)

### 2. Сборка проекта

* **Debug-сборка:**
  ```bash
  cargo build
  ```
* **Release-сборка:**
  ```bash
  cargo build --release
  ```

### 3. Прошивка бинарного файла в ESP32

Сборка и загрузка прошивки на подключенную плату (требуется установленный раннер `espflash` или `cargo-espflash`):

* **Debug-загрузка:**
  ```bash
  cargo run
  ```
* **Release-загрузка:**
  ```bash
  cargo run --release
  ```
